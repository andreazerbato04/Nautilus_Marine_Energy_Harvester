# Nautilus Marine Energy Harvester #
The Nautiuls project is an open source, the goal is build a buoy for take information with the sensor in the lagoon of venice. Like an open source project averyone is free to add more information or data for the creation of the buoy. The main idea is a hybrid harvesting system based in a electromagnetic pendulum and a solar panel put in parallel. This is because the project want to use a green energy and want to keep data in the winter period and in the summer period, the solar panel is more efficient in the spring and summer whene there is more day of sun and the pendulum is more effcient in the autumn and winter period where there is more cloud and wind and for this reason more wave. The idea is storage this energy in battery and use it to charge a low energy sensor. In fact in the venice lagoon is important to take more information
