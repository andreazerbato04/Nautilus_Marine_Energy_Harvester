# REFERENCES #
<ul><li><b><h3>Self-powered wireless sensor system for water monitoring based on low-frequency electromagnetic-pendulum energy harvester:</h3> </b>
https://www.sciencedirect.com/science/article/abs/pii/S0360544222007861?via%3Dihub<br><br>
A complete open-source reference for a low-frequency wave energy harvesting sensor is the Water-Wave Self-Powered Wireless Sensor design by Li et al. (2022), which integrates a 1.5 Hz eccentric electromagnetic pendulum harvester, a boost-converter PMS with hysteresis control (operating down to 0.8V), and a low-power ZigBee MCU node (measuring TDS and temperature) into a compact, sealed floating hull. The project provides detailed validation on low-voltage energy accumulation, low-impedance coil optimization (4.22 Ω), and continuous battery-free operation under small wave amplitudes (>1.2 cm).</li> <br><br>
<li><b><h3>  A fully packed spheroidal hybrid generator for water wave energy harvesting and self-powered position tracking:</h3> </b>
  https://www.sciencedirect.com/science/article/abs/pii/S2211285519311565?via%3Dihub <br><br>
A prominent reference for a multi-source wave energy harvesting smart buoy is the Spheroidal Hybrid Generator (SB-HG) by Chandrasekhar et al. (2019), which combines a Triboelectric Nanogenerator (TENG) and an Electromagnetic Generator (EMG) driven by a sliding inner mechanism, supplemented by a top-mounted solar cell for low-wave conditions. The system powers a long-range (LoRa) position-tracking node and achieves peak outputs of 100V / 2µA (TENG) and 20V / 15mA (EMG) to continuously charge capacitors and a lithium-ion battery. The project provides key design principles for packing low-frequency kinetic harvesters inside a fully sealed, waterproof spheroidal floating hull for self-powered marine tracking and environmental monitoring. <br><br></li>
<li><b><h3>Smart Buoy:    </h3>   </b>
  https://github.com/sk-t3ch/smart-buoy/tree/master/docs <br><br>
The most complete open-source reference for a marine IoT buoy is the Smart Buoy project by sk-t3ch, which integrates four solar panels, a GPS module, an accelerometer (for wave heightmeasurement), and NRF24 radio communication with a Raspberry Pi base station into a 3D printed PETG hull. The project provides detailed documentation on waterproofing strategy,buoyancy calculation, and solar charge controller integration. The Nautilus Harvester adopts the general hull design philosophy and solar architecture from this reference, adding the EMG pendulum module to the lower level.<br><br></li>
<li><b><h3>Rotational EMG Harvester </h3></b>
https://github.com/tiandahuang/keh-har-sensor<br><br>
A fully custom 3D-printed rotational unbalanced mass electromagnetic harvester, designed originally for wearable human motion sensing, provides directly applicable CAD geometry and PCB design for the Nautilus Harvester's generator module. The rotor, stator, magnet placement, and custom rectifier PCB from this project serve as the scaling reference for the buoy-scale pendulum design. <br><br></li>
<li><b><h3>MBARI Wave energy converter: </h3></b>
https://github.com/osrf/mbari_wec<br>
https://github.com/osrf/mbari_wec_gz<br>
https://github.com/osrf/mbari_wec_utils<br><br>
<br><br>The MBARI Wave Energy Converter simulation framework — implemented in the Gazebo robotics simulator with full hydrodynamic modelling — provides validated mathematical tools for simulating buoy power take off dynamics. This framework can be used to numerically verify the expected energy yield of the Nautilus Harvester pendulum under Venice Lagoon wave conditions.</li>
